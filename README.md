# LOVAN

LOVAN is a free streaming platform for films and series, created and run by LOVAN Studio in Uganda.

Website: https://lovan.site
Telegram: https://t.me/lovansite

## About

LOVAN was designed, built and is maintained by LOVAN Studio. Viewers can browse, search, watch online, save titles to My List, continue watching, use subtitles and download titles for offline viewing.

## Development

```sh
npm i
npm run dev
```
